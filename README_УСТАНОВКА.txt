OIL MANAGEMENT — REBUILD 23

1. Сохраните резервную копию своей карьеры перед обновлением.
2. Распакуйте архив и загрузите ВСЕ файлы и папки в корень GitHub-репозитория oil-management.
3. Убедитесь, что index.html и папки js, css находятся в корне репозитория, а не внутри дополнительной папки.
4. Дождитесь завершения GitHub Actions / Pages.
5. Откройте опубликованный сайт в новой вкладке. Внизу справа должен быть индикатор «Rebuild 23».
6. Если индикатор отсутствует, на сайте ещё старая сборка: проверьте публикацию и очистите кэш Safari/Chrome.

Ключевые изменения:
- Один объединённый JS-файл js/game-rebuild23.js вместо цепочки конфликтующих скриптов.
- Один рендерер диспетчерской.
- Отдельные карточки для каждой скважины, РВС, насоса и КТП из данных игры.
- На старте новой малой компании один РВС, а не три фиктивных.
- Начальные договоры покупателей не создаются автоматически.

Проверки:
- node --check: успешно.
- ZIP CRC: успешно.
- Изолированный тест генератора карточек: 2 скважины + 2 РВС + 2 насоса + 2 КТП = 8 отдельных карточек; остановленная скважина показывает 0 т/сут.
- Полный запуск в Chromium не проведён: среда блокирует открытие локальных страниц (ERR_BLOCKED_BY_ADMINISTRATOR).

Ограничение: старые сохранения могут содержать старые объекты и историю. Обновление не должно удалять пользовательские объекты из сохранения. Для проверки начального состава используйте «Новая карьера» только после резервного сохранения.
